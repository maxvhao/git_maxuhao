# git_maxuhao

本仓库由 Codex 在 `C:\git_codex` 目录初始化，并推送到 GitHub。

## 仓库地址

- GitHub: https://github.com/maxvhao/git_maxuhao

## 克隆

```bash
git clone https://github.com/maxvhao/git_maxuhao.git
```

## 说明

- 默认分支：`main`
- 仓库当前包含 `README.md`、`.gitignore` 与 `first.txt`，可在此基础上继续开发。
- 若本机直连 GitHub 不通，可为 git 配置代理：

```bash
git config --global http.https://github.com.proxy http://127.0.0.1:7890
```
